# Site icons

Drawn by Maria, 2026-07-28. Copied verbatim to the *root* of the built
site (not `assets/`), because `/favicon.ico` is where a browser guesses
before it has read a single page. The pages still declare every icon
with relative links, so nothing here assumes the site is hosted at a
domain root. `site.webmanifest` follows the same rule: relative `src`
paths only, and its colours are the design system's `--prussian` and
`--ground`.

This README stays out of the build.
